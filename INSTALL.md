# Установка на Windows за Nginx Proxy Manager

Пошаговая инструкция: сайт работает на компьютере с Windows 10/11 и открывается по адресу **https://hvostdoc.online** через Nginx Proxy Manager (NPM).

```
Браузер ──HTTPS──▶ Nginx Proxy Manager ──HTTP──▶ Сделано (waitress)
                   80/443, сертификат          127.0.0.1:47391
                   Let's Encrypt               только этот компьютер
```

Сайт слушает **нестандартный порт 47391** и только локальный адрес, поэтому снаружи напрямую недоступен. Всё публичное идёт через NPM.

---

## 1. Что нужно заранее

| | |
|---|---|
| **Windows 10 или 11** | Тот же компьютер, где работает Nginx Proxy Manager (или любой другой в той же сети, см. раздел 9). |
| **Python 3.12 или 3.13** | [python.org/downloads](https://www.python.org/downloads/). При установке отметьте **Add python.exe to PATH**. Подойдёт и 3.10–3.14. |
| **Nginx Proxy Manager** | Уже работает и доступен из интернета по портам 80 и 443. |
| **Домен hvostdoc.online** | Доступ к DNS в личном кабинете REG.RU. |

Node.js и Chrome нужны только для необязательных браузерных тестов (`06_RUN_TESTS.bat`), для работы сайта они не требуются.

## 2. Скачать проект

Вариант А, через Git:

```bat
cd C:\Sites
git clone https://github.com/<ваш-логин>/sdelano.git
```

Вариант Б: на GitHub нажмите **Code → Download ZIP** и распакуйте, например, в `C:\Sites\sdelano`.

> Лучше короткий путь без пробелов, например `C:\Sites\sdelano`. Рабочий стол тоже подойдёт, но для автозапуска надёжнее папка вне профиля пользователя.

## 3. Установить: `01_INSTALL.bat`

Дважды щёлкните **`01_INSTALL.bat`**. Скрипт:

1. найдёт подходящий Python;
2. создаст изолированное окружение `.venv` (системный Python не меняется);
3. установит единственную зависимость, сервер **waitress 3.0.2**, с проверкой SHA-256: подменённый пакет не установится;
4. создаст файл настроек `local_config.bat` (порт 47391, домен hvostdoc.online);
5. прогонит самопроверку (29 тестов сервера);
6. проверит, что порт свободен.

В конце будет надпись `Installation complete`.

> **Важно, если NPM стоит на другой машине** (как в схеме с `192.168.1.10`): после каждой чистой установки запустите `09_PROXY_ACCESS.bat <IP прокси>`. Новая установка создаёт `local_config.bat` с безопасным адресом `127.0.0.1`, и без этого шага NPM покажет **502 Bad Gateway**. При обновлении поверх старой папки `local_config.bat` сохраняется, и повторять шаг не нужно.

## 4. Запустить: `02_START.bat`

Дважды щёлкните **`02_START.bat`**. Сайт запустится в фоне, а в браузере откроется `http://127.0.0.1:47391`. Окно можно закрыть, сайт продолжит работать.

Если порт занят другой программой, скрипт так и скажет. Тогда откройте `local_config.bat` в Блокноте, поменяйте `SDELANO_PORT` на любой свободный номер от 20000 до 48000 и запустите `02_START.bat` снова. Тот же номер потом укажите в NPM.

## 5. DNS в REG.RU

Личный кабинет REG.RU → **Домены → hvostdoc.online → DNS-серверы и управление зоной**. Нужны две записи:

| Тип | Имя (субдомен) | Значение |
|---|---|---|
| `A` | `@` | внешний IP-адрес сервера, на котором работает NPM |
| `CNAME` | `www` | `hvostdoc.online.` |

Внешний IP можно узнать, открыв на сервере [2ip.ru](https://2ip.ru). Если в зоне уже есть другие `A`-записи для `@` или `www`, удалите их, иначе часть посетителей попадёт не туда. DNS обновляется от нескольких минут до нескольких часов.

## 6. Nginx Proxy Manager

Откройте панель NPM (обычно `http://<IP-сервера>:81`) → **Hosts → Proxy Hosts → Add Proxy Host**.

**Вкладка Details**

| Поле | Значение |
|---|---|
| Domain Names | `hvostdoc.online` и `www.hvostdoc.online` |
| Scheme | `http` |
| Forward Hostname / IP | см. таблицу ниже |
| Forward Port | `47391` (или ваш порт из `local_config.bat`) |
| Cache Assets | выключено: сайт сам управляет кэшем |
| Block Common Exploits | **включено** |
| Websockets Support | выключено: не нужно |

Что указать в **Forward Hostname / IP**:

| Где работает NPM | Forward Hostname / IP | `SDELANO_HOST` в `local_config.bat` |
|---|---|---|
| В Docker Desktop на этом же Windows | `host.docker.internal` | `127.0.0.1` (по умолчанию) |
| Установлен на этом же Windows без Docker | `127.0.0.1` | `127.0.0.1` (по умолчанию) |
| На другом компьютере или в виртуальной машине | локальный IP этого Windows, например `192.168.1.20` | запустите `09_PROXY_ACCESS.bat` (раздел 9) |

**Вкладка SSL**

| Поле | Значение |
|---|---|
| SSL Certificate | **Request a new SSL Certificate** |
| Force SSL | **включено** |
| HTTP/2 Support | **включено** |
| HSTS Enabled | выключено: сайт уже отправляет заголовок HSTS сам |
| Email / I Agree | ваша почта и согласие с условиями Let's Encrypt |

Нажмите **Save**. Через 10–30 секунд NPM получит сертификат.

> Сертификат выдаётся, только если DNS уже указывает на сервер, а порты 80 и 443 проброшены на NPM. Если NPM пишет *Internal Error*, подождите обновления DNS и повторите.

Вкладку **Advanced** заполнять не нужно: все заголовки безопасности сайт отдаёт сам.

## 7. Проверка

1. Откройте **https://hvostdoc.online**: должен открыться список задач с замком в адресной строке.
2. **https://www.hvostdoc.online** должен перенаправить на адрес без `www`.
3. **https://hvostdoc.online/health** должен показать `{"status": "ok", "service": "sdelano", ...}`.
4. Необязательно: проверьте заголовки на [securityheaders.com](https://securityheaders.com/?q=hvostdoc.online). Ожидаемая оценка: **A+**.
5. На компьютере с сайтом запустите **`05_STATUS.bat`**: там видны состояние, порт и автозапуск.

## 8. Автозапуск вместе с Windows

Запустите **`07_AUTOSTART_ON.bat`** и подтвердите запрос прав администратора. Скрипт:

- создаст задание Планировщика **«Sdelano Web»**, которое запускает сайт при старте Windows, ещё до входа пользователя;
- запустит сайт от встроенной учётной записи **LOCAL SERVICE** с минимальными правами: она может читать папку проекта и писать только в `data\`. Если на этом компьютере так не получится (например, Python установлен в закрытую папку), скрипт предупредит и включит запасной режим от учётной записи SYSTEM;
- настроит автоматический перезапуск через минуту, если сайт когда-нибудь упадёт.

Выключить автозапуск: **`08_AUTOSTART_OFF.bat`**.

Пока автозапуск включён, `02_START`, `03_STOP` и `04_RESTART` сами попросят права администратора: ими управляется системное задание.

## 9. Если NPM работает на другом компьютере

Так бывает чаще всего: NPM стоит на отдельной машине или в виртуалке (например, `192.168.1.10`), а сайт на этом Windows. По умолчанию сайт слушает только `127.0.0.1`, и с другой машины до него не достучаться: NPM ждёт ответа и отдаёт ошибку по тайм-ауту.

Всё настраивает один скрипт. Запустите **`09_PROXY_ACCESS.bat`** (он сам попросит права администратора) и введите IP машины с NPM. Его видно в адресе панели NPM, например `http://192.168.1.10:81`. Можно указать сразу: `09_PROXY_ACCESS.bat 192.168.1.10`.

Скрипт:

1. переключит сайт на `0.0.0.0` (все сетевые интерфейсы);
2. откроет порт в брандмауэре Windows **только для IP прокси**;
3. включит вторую линию защиты: сам сайт будет отклонять соединения с любых других адресов (`SDELANO_TRUSTED_PROXY`), даже если брандмауэр однажды отключат;
4. отключит блокирующее правило брандмауэра для Python, если такое осталось от закрытого всплывающего окна;
5. перезапустит сайт и напишет, что указать в NPM.

В NPM для `hvostdoc.online` укажите: **Scheme** `http`, **Forward Hostname / IP** = локальный IP этого Windows (скрипт его покажет, например `192.168.1.20`), **Forward Port** `47391`.

Вернуть режим «только этот компьютер»: `09_PROXY_ACCESS.bat off`.

Порт 47391 **не нужно** пробрасывать на роутере: из интернета к нему ходит только NPM.

> **Если на этом Windows уже работает свой обратный прокси** (через который NPM отдаёт другие сайты), можно вместо этого добавить в него маршрут для `hvostdoc.online` на `127.0.0.1:47391`. Оба варианта рабочие. `09_PROXY_ACCESS.bat` проще и не затрагивает другие сайты.

## 10. Обновление

```bat
03_STOP.bat
git pull            (или замените файлы новыми из ZIP, сохранив local_config.bat)
01_INSTALL.bat
02_START.bat
```

Задачи пользователей хранятся в их браузерах, поэтому обновление сервера их не затрагивает. Офлайн-кэш в браузерах обновится сам при следующем визите.

## 11. Все файлы управления

| Файл | Что делает |
|---|---|
| `01_INSTALL.bat` | Установка и самопроверка. Можно запускать повторно, это безопасно. |
| `02_START.bat` | Запустить сайт в фоне. |
| `03_STOP.bat` | Остановить сайт. Останавливается только процесс этой установки. |
| `04_RESTART.bat` | Перезапустить (например, после изменения `local_config.bat`). |
| `05_STATUS.bat` | Состояние: работает ли сайт, порт, адреса, автозапуск. |
| `06_RUN_TESTS.bat` | Все тесты. Браузерные запускаются, если установлен Node.js 22+. |
| `07_AUTOSTART_ON.bat` | Включить запуск вместе с Windows. |
| `08_AUTOSTART_OFF.bat` | Выключить автозапуск. |
| `09_PROXY_ACCESS.bat` | Открыть доступ для NPM на другой машине (и только для него). |
| `local_config.bat` | Настройки: порт, адрес, домен. Создаётся при установке и в Git не попадает. |

Журналы лежат в `data\logs\`: `server.log` (ошибки сервера), `service.log` (автозапуск), `server-console.log` (ручной запуск).

## 12. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `Python was not found` | Установите Python с [python.org](https://www.python.org/downloads/) и отметьте *Add python.exe to PATH*. Перезапустите `01_INSTALL.bat`. |
| `Порт 47391 занят` | Смените `SDELANO_PORT` в `local_config.bat` и в NPM. Порты, которые резервирует Windows: `netsh int ipv4 show excludedportrange protocol=tcp`. |
| NPM показывает **502 Bad Gateway** или **504 Gateway Time-out**, сайт долго не открывается | Сайт не запущен (`05_STATUS.bat`) или NPM не может до него достучаться. NPM на другой машине: запустите `09_PROXY_ACCESS.bat` (раздел 9). NPM в Docker Desktop на этом же Windows: Forward Hostname `host.docker.internal`. |
| Сайт открывается, но через какое-то время пропадает | Включите автозапуск `07_AUTOSTART_ON.bat`: сайт будет работать как служба и перезапускаться сам. |
| Браузер показывает **«Доступ только через прокси» (403)** | Включена защита из раздела 9, а запрос пришёл не от NPM. Проверьте IP в `SDELANO_TRUSTED_PROXY` в `local_config.bat` или повторите `09_PROXY_ACCESS.bat`. |
| Браузер показывает **«Неизвестный адрес сайта» (421)** | Сайт открыт по имени, которого нет в списке разрешённых. Это защита от подмены хоста. Добавьте имя в `SDELANO_EXTRA_HOSTS` или исправьте `SDELANO_PUBLIC_URL`, затем `04_RESTART.bat`. |
| NPM не выдаёт сертификат | DNS ещё не обновился или порты 80/443 не проброшены на NPM. Проверьте: `nslookup hvostdoc.online`. |
| `02_START.bat` пишет, что сайт не ответил | Смотрите `data\logs\server.log` и `server-console.log`. Часто помогает переустановка: удалите `.venv` и запустите `01_INSTALL.bat`. |
| Антивирус блокирует `python.exe` | Добавьте папку проекта в исключения: сайт не скачивает и не запускает ничего постороннего. |

## 13. Удаление

`08_AUTOSTART_OFF.bat` (если включали) → `03_STOP.bat` → удалите папку проекта и Proxy Host в NPM.
