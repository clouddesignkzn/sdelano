# Безопасность

## Модель угроз

«Сделано» состоит из статического сайта и маленького сервера, который его раздаёт. Задачи хранятся только в браузере пользователя: сервер их не получает, не хранит и не обрабатывает. Это убирает целые классы рисков (утечки базы, учётные записи, CSRF, SQL-инъекции). Оставшиеся риски закрыты так:

### Браузер

| Риск | Защита |
|---|---|
| XSS через текст задачи, поиск или файл импорта | Текст выводится только через `textContent`, `value` и `createElement`. CSP запрещает инлайн-скрипты и `eval`. **Trusted Types** (`require-trusted-types-for 'script'`) не дают выполнить `innerHTML` и подобные операции, даже если такой код однажды появится. Это проверяют e2e-тест и статическая проверка кода. |
| Подмена или порча данных в `localStorage` | Всё прочитанное проходит проверку по белому списку полей, объекты собираются заново (защита от prototype pollution). Повреждённые данные восстанавливаются из резервной копии. |
| Вредоносный файл импорта | Лимит 1 МБ, проверка структуры, подтверждение перед заменой, отмена после. |
| Невидимые и bidi-символы (Trojan Source, подмена вида текста) | Удаляются при вводе: управляющие, bidi-override, zero-width. ZWJ сохраняется, чтобы не ломать эмодзи. |
| Clickjacking | `frame-ancestors 'none'` и `X-Frame-Options: DENY`. |
| Утечки через Referer и сторонние ресурсы | `Referrer-Policy: no-referrer`, `default-src 'none'`. Внешних запросов нет совсем: шрифты и иконки свои. |
| Подмена скрипта service worker | Регистрация идёт через политику Trusted Types `sdelano-sw`, которая разрешает только `./sw.js`. |
| Межсайтовые атаки на процесс (Spectre и т. п.) | COOP `same-origin`, COEP `require-corp`, CORP `same-origin`, `Origin-Agent-Cluster`. |
| Лишние возможности браузера | Permissions-Policy отключает камеру, микрофон, геолокацию, платежи, USB и т. д. |

### Сервер (`server/`, `launcher.py`)

| Риск | Защита |
|---|---|
| Обход путей (`../`, `%2e%2e`, `\`, `%00`) | Файлы из `public/` загружаются в память при старте по белому списку расширений. Запрос ищется в словаре, файловая система во время работы не используется. Скрытые файлы и симлинки пропускаются. |
| Подмена Host, DNS rebinding | Принимаются только разрешённые имена (домен, www, localhost). Остальное получает ответ `421`. `www` перенаправляется на основной домен, в `Location` попадают только известные пути (нет открытого редиректа). |
| Нестандартные методы | Разрешены только `GET` и `HEAD`, остальные получают `405`. |
| Перегрузка и медленные клиенты | Лимиты waitress: заголовки до 16 КБ, тело до 64 КБ, тайм-аут соединения 30 с, не больше 500 соединений. Перед сервером стоит Nginx Proxy Manager. |
| Утечка сведений о сервере | Заголовок `Server` не отправляется, трассировки ошибок наружу не выдаются. |
| Прямой доступ из интернета | По умолчанию сервер слушает только `127.0.0.1` на нестандартном порту. Наружу смотрит только NPM с HTTPS. Если NPM на другой машине, порт открывается в брандмауэре только для его IP, а сервер сам отклоняет все остальные адреса (`SDELANO_TRUSTED_PROXY`, ответ `403`). |
| Неверные настройки | Каждое значение `SDELANO_*` проверяется. С ошибкой сервер не запустится и объяснит, что исправить. |
| Остановка чужих процессов | `launcher.py stop` завершает процесс, только если его командная строка совпадает с этой установкой. |
| Права службы | Автозапуск работает от **LOCAL SERVICE**: чтение проекта и запись только в `data\`. |
| Цепочка поставок | Одна зависимость (`waitress`), закреплённая по SHA-256 (`pip --require-hashes`). В CI используются официальные actions, `persist-credentials: false` и минимальные `permissions`. |

## Где задаются политики

- `server/security.py` задаёт HTTP-заголовки. Это единственный источник правды.
- `public/index.html` дублирует CSP в `<meta>` на случай другого хостинга. Тест `StaticChecks.test_meta_csp_matches_header` следит, чтобы политики совпадали.
